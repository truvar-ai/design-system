# @truvar-ai/design-system

## 0.0.1

### Patch Changes

- 8a386c5: Accessibility and bundle size. `ChartCard`, `OSTaskCard`, `AppWindow` and `DeviceCard` take `headingLevel` (3 by default, was a fixed 4) so their titles fit the page's heading order. `Slider` with only `aria-label` no longer renders an empty label, so screen readers hear its name. The solid danger button keeps readable text in dark mode when the theme follows the device. Flags and phone number data are now separate files in the package: apps that don't render `Flag`, `PhoneField` or `CountryPicker` no longer download them.
- 8a386c5: The four brand fonts (Poppins, DM Sans, Alexandria, IBM Plex Sans Arabic) now come with the package. Import `@truvar-ai/design-system/fonts.css` before `styles.css` and your app serves them itself, with no request to Google Fonts.
- 8a386c5: Add `@truvar-ai/design-system/crm`: a unified inbox for 19 channels (`ConversationInbox`, `ConversationList`, `MessageThread`, `Composer`, `ContactPanel`), AI handoff with an auto-resume timer (`AiAgentBar`, `useAiHandoff`), contact records (`ContactHeader`, `PropertyList`, `ActivityTimeline`, `CallSheet`) and roles and permissions (`RoleList`, `PermissionMatrix`). Add 24 icons for conversations and teams.
- 8a386c5: Country names and their alphabetical order (phone field, country picker, maps) now come with the package instead of the browser's Intl data. Node and each browser ship different name data, so server-rendered pages in Next.js didn't match the browser and React threw a hydration error. Run `pnpm build:countries` to refresh the names.
- 8a386c5: Add `BottomNav` and `BottomNavItem`, the phone tab bar. Add brand themes: EasySocials (`data-brand="easysocials"`, `BrandProvider`, `EasySocialsMark`), with `Logo` drawing the current brand. `Sheet` can be controlled with `isOpen` and `onOpenChange`. Touch and pointer layer: no tap flash, hover only on devices that hover, pressed feedback, finger-sized hit areas, and the right cursor on every interactive element.
- 8a386c5: `react-is` is now a peer dependency, so charts use the copy that matches your React version (18 or 19). npm and pnpm install it automatically.
- 8a386c5: Server rendering (Next.js) without hydration errors. Every number, date and amount the components show now comes out exactly the same on the server and in every browser. Add `numberFormat`, `dateFormat` and `relativeTimeFormat`: drop-in replacements for `new Intl.NumberFormat`, `new Intl.DateTimeFormat` and `new Intl.RelativeTimeFormat`, for your own formatting. The call player reads its theme colours after it mounts, so pages with it can render on the server.
- 8a386c5: Add `@truvar-ai/design-system/widget`: an embeddable website assistant with text, voice notes and live voice calls, agent steps, time slots, inline forms, approvals, choice cards and results (`WebWidget`, plus each part on its own). On phones it takes over the screen like an app. Add phone app pieces: `PushLayout`, a side menu that slides the whole app aside; `useHideOnScroll`, bars that step aside while you read; `useSystemBars`, the phone's status bar following the page and dimming with open sheets. `BottomNav` takes `isHidden`. `UserMenu` opens as a bottom sheet on phones. Closing the push menu no longer shows the menu around the app as it slides back.
